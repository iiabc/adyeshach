# Adyeshach

## 下载
你可以通过以下链接下载 Adyeshach 的最新版本：

- [自动构建分发平台](https://pakko.hiusers.com/resource/adyeshach)

## 特征

- 已支持至 1.21.X 版本
- 需要前置插件：
    - [PacketEvents](https://modrinth.com/plugin/packetevents)
- 支持模型：BetterModel、ModelEngine

## 构建

**Windows 平台**
```shell
gradlew.bat clean build
```

**macOS/Linux 平台**
```shell
./gradlew clean build
```
